# Storia_TRPG
TRPG 서비스를 제작해보는 1인 프로젝트



## 파일구조
```
Storia_TRPG/
├── backend/          # FastAPI (기존 코드)
│   ├── core/  routers/  schemas/
│   ├── main.py
│   ├── requirements.txt
│   └── Dockerfile
├── frontend/         # 예: npm create vite@latest frontend
├── data/srd/         # SRD JSON (몬스터, 주문 등)
├── docs/             # 설계 문서, 프롬프트 설계
├── render.yaml       # 백엔드와 프론트를 한 번에 배포
├── ATTRIBUTION.md    # SRD 출처 표기 (CC-BY-4.0)
├── .gitignore
└── README.md
```
